03 — Reversal

Changing your mind is the hard part.

Most memory tools keep both versions and let similarity sort it out. Loci stops a new decision when it clearly overlaps one already in force: nothing is written until you retire the old claim with supersedes or choose to keep both. The brief carries the active claims and the append-only log still contains the receipt.

An overlapping decision is not saved by accident.
Overlap is judged from shared subject words, so the check is not semantic: rephrasing the same decision merges, and a synonym with no word in common can still get through.
The write comes back with the conflicting ids and both ways forward: replace, or keep both on purpose. Retired claims leave the brief, search, and export, but stay in memories.jsonl so you can answer “why did we change this?” six months later.

04 — Your files

The answer is in a document. Now the assistant can cite it.

Memory is what you told it. A knowledge base is what your files already say. Loci keeps them separate on purpose: a memory is a claim you can retire, while a file is evidence, and every excerpt names the document and the part it came from.

Import locally

Add a file in the Files tab, or run loci docs add. Text, Markdown, HTML, RTF, DOCX, and text-based PDF are extracted on your machine. A scan or a photo can be read with Windows OCR when you tick that option for that import; normal extraction always runs first. Edit the file and import it again: Loci updates that document instead of making a duplicate, and the Files view marks a file that changed or vanished on disk, refreshing the mark while it is open.

No cloud conversion · OCR is opt-in on Windows · stale files are marked

Answers point at the passage

Markdown headings start new parts, so “Refunds” does not trail into “Support”. Code files split at lines, not at # comments. The assistant gets a citation like ["MSA 2026" — § Termination], not an unattributed summary. Plain text falls back to the part number.

Click a result to read the source · comments never become fake headings

Only the match enters

Documents stay out of the default brief. A folder of manuals cannot crowd out the decisions that are always relevant; a file appears only when the current question matches it.

Twelve tools total · 4 for files, 8 for memory

A search box finds text. A citation tells you which text, and where.

05 — Auto-capture

You will forget to say remember.

So Loci listens to the only side that carries your intent: the messages you type. While you work in OpenCode, an optional plugin reads what you send and files the durable parts — a preference, a decision, who you are — without waiting to be asked.

Everything else is ignored. Assistant replies, tool output, pasted logs, fenced code, quotations, and slash commands never reach the store.

Automatic capture is a trade, not a trick.
It buys coverage at the cost of store purity. The confidence gate and the review digest are the safeguard. Everywhere else, capture stays manual: paste a chat, keep the lines you choose.
Write gateson by default
  • 0.8 or higher, durable kind only — person, preference, decision, or other. Saved as inferred, with your exact sentence kept as the origin.
  • 0.6 to 0.8, or any fact or project — review queue. Nothing enters the brief until you approve it.
  • Weaker or non-durable — dropped. No draft, no placeholder.
OpenCode only, and opt-in. Install the plugin with loci plugin opencode on. loci auto off is the single switch that stops automatic capture.

10 — Questions

Questions people actually ask.

Does it work with ChatGPT?+

The web app yes, through a small browser extension — but only by click. ChatGPT cannot launch a local MCP server, so the extension fetches your brief from Loci on your machine and inserts it into the chat input when you click its button; you send the message yourself. Nothing is captured from the page and nothing is sent automatically. The inserted text ends with one plain line saying it is background context, not a question, so the model reads it and waits for what you ask next. The native tools work with Claude Desktop, Cursor, OpenCode, Windsurf, and Zed.

Does it start when Windows does?+

If you want it to. One shortcut, visible in your Startup menu, starts a minimized server when you log in; delete the shortcut and it stops. Nothing hides in the registry and nothing runs that you cannot see. If you prefer to open Loci yourself, the Desktop shortcut works exactly as before.

Do I need Node.js?+

No. The Windows download includes its own runtime. Extract the zip, double-click install.bat, restart your assistant. That is the whole setup.

Is my data sent anywhere?+

No. There is no account and no server. The only copies are the files in your .loci folder and whatever you choose to export or paste.

Does it read my chats automatically?+

Only if you turn it on, and only in OpenCode. The optional OpenCode plugin reads the messages you type, saves durable high-confidence preferences, decisions, and identity details; the borderline ones wait in review, and weak matches are dropped. It never reads assistant replies, tool output, or your screen. In every other app, use From a chat to paste a conversation, review the lines it found, and save only what you choose; through MCP an assistant can add a memory after you ask it to remember something. loci auto off stops automatic capture.

Can it search my own files?+

Yes. Add a local document in the Files tab. Loci extracts the text on your machine, splits it at Markdown headings (or lines for code), indexes each part, and returns the matching excerpt with the document name and, when it has one, the heading. Import the edited file again and it updates that document instead of duplicating it; if the source file has since changed or vanished, the listing says so. A scan or an image with no text layer is refused unless you opt in to Windows OCR for that import. Nothing leaves the machine.

What happens when I change my mind?+

Loci will not quietly stack an overlapping decision on top of the first. The write comes back with the old claim and both ways out. Retire the old memory — the ⊘ button in the window, or --supersedes on the command line — and the new claim becomes active. Or keep both on purpose with --force. The old one leaves the brief and search either way, and the history stays in the log for audit.

Can I use it across several projects?+

Yes. Memories are global by default. Use the switch in the header to open any folder — a code project, a client folder, or a course — and Loci keeps a second store for it. The window and the brief can be scoped to global, project, or both. The last folder you opened is remembered and restored next time, if it still exists.

What if I move to another PC?+

Back up on the old machine downloads every memory and imported file as one JSON file; import it on the new one. The store is plain text, so you can also copy the .loci folder yourself.

Is this a subscription?+

No. One payment. The version you buy is yours. If a future major version is worth charging for, it will be a separate purchase — you will not be forced to upgrade and nothing will stop working.

Windows only?+

The installer is for Windows 10 and 11. The engine is plain Node with no native modules, so it runs on macOS and Linux from source today; packaged installers for those are not available yet.
